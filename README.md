# Güvenli Doğal Gaz Kullanımı - Mini Oyunlar

Bu proje, Phaser 3 ile geliştirilmiş, güvenli doğal gaz kullanımı konusunda eğitici mini oyunlar içeren bir web uygulamasıdır.

## Proje Yapısı

- `index.html` : Ana HTML dosyası
- `src/main.js` : Phaser oyun başlatıcı ve sahne yönetimi
- `src/scenes/` : Oyun sahneleri (Ana Menü, Mini Oyunlar)
- `assets/` : Oyun varlıkları (görseller, sesler vs.)

## Geliştirme

1. Bağımlılıkları yükleyin:
   ```sh
   npm install
   ```
2. Geliştirme sunucusunu başlatın:
   ```sh
   npm start
   ```
3. Üretim için derleyin:
   ```sh
   npm run build
   ```

## Notlar
- Proje, React veya başka bir framework kullanmaz.
- Responsive ve genişletilebilir yapıdadır.
- `src/scenes/` klasörüne yeni mini oyun sahneleri ekleyebilirsiniz.
